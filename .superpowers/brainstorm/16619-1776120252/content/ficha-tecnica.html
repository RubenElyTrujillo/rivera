¿Cómo maneja el cliente la ficha técnica del producto?

Actualmente los campos son fijos (grosor, clase de uso, garantía…). ¿Cómo quiere el cliente editarla?

A

Campos fijos estructurados (lo que ya existe)

El admin tiene inputs para: grosor, clase de uso, resistencia al agua, tipo de instalación, garantía. Rápido de llenar, pero no flexible.

Pros

  • Ya existe
  • Consistente entre productos

Contras

  • No puede agregar info extra
  • Diseño fijo
B

Editor Markdown + campos fijos (Recomendado ⭐)

Se mantienen los campos estructurados para datos clave, y se agrega un editor de texto enriquecido (Markdown) para contenido libre: tablas, párrafos, listas.

Pros

  • Fácil para el cliente
  • Flexible para info extra
  • Sin riesgo de HTML roto

Contras

  • Requiere agregar campo en DB
C

Editor HTML completo

Un editor visual (WYSIWYG) que genera HTML. El cliente puede poner tablas, imágenes, cualquier estructura.

Pros

  • Máxima libertad

Contras

  • HTML malo puede romper el diseño
  • Más pesado de implementar
  • Cliente puede meter código roto
