# Phase 1 — DB & Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the data layer for the modular redesign: new `Category`, `NavItem`, and `PageSection` models; extend `MaterialFinish` with hover image and technical spec fields; add `categoryId` to `Material`; create repos, schemas, and types for all new models.

**Architecture:** All new models follow the same repository pattern already established in the codebase (Prisma → typed repository → Zod schema → TypeScript interface). No business logic in repos — only data access. All new fields on existing models are optional/defaulted so existing data and UI continue to work without changes.

**Tech Stack:** Prisma 7, PostgreSQL, Zod, TypeScript, Jest
