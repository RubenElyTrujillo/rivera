Diseño — Sección 1: Modelo de Datos

Las 4 tablas nuevas que reemplazan todo lo anterior

📁 Categoria
id Int
name String
slug String @unique
coverImage String?
description String?
order Int
URL: /[slug]
Ej: /pisos-laminados
→
📂 Subcategoria
id Int
categoriaId Int (FK)
name String
slug String @unique
coverImage String?
hoverImage String?
description String?
order Int
URL: /[catSlug]/[slug]
Ej: /pisos-laminados/splash
→
📦 Producto
id Int
subcategoriaId Int (FK)
name String
slug String @unique
coverImage String?
shortDesc String?
htmlContent Text?
order Int
URL: /producto/[slug]
Ej: /producto/arctic-oak-splash
→
🖼 ProductoImagen
id Int
productoId Int (FK)
url String
caption String?
order Int
Galería del producto
(opcional, múltiples)
🗑 Se eliminan: Category, Material, MaterialCollection, MaterialFinish, MaterialFinishImage (y sus migraciones previas se dejan como histórico, la DB se limpia con una migración nueva).
